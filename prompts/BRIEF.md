# 제작 프롬프트 형식 (BRIEF)

장표 하나를 시킬 때 이 다섯 줄만 채운다. **순서가 중요하다.**

```
1. 결론    이 장표를 보고 무엇을 알아야/결정해야 하나 — 한 문장
2. 원천    파일 경로. 시트·범위를 알면 같이
3. 독자    경영진 / 실무 / 외부
4. 형식    자유 · 표 중심 · 차트 중심   (모르면 "자유")
5. 제약    꼭 넣을 것, 빼야 할 것, 밝혀야 할 한계
```

## 왜 이 순서인가

2026-08-30에 한 장표를 다섯 번 만들면서 재작업이 어디서 나는지 셌다.

| 잡 | 재작업 | 프롬프트에 있던 것 |
|---|---|---|
| 003 v1 | **4건** | 형식만 — "시계열 차트 만들고 상관 해설 붙여줘" |
| 004 | 3건 | 원천만 — "내용 현황을 요약해줘" |
| 005 | 거의 0 | **결론이 이미 정해져 있었다** (004에서 나옴) |

003은 "무엇을 말하려는가"가 없어서 **결론이 그림에 없는 장표**가 나왔다.
CRITIC이 CRITICAL로 잡은 것이 정확히 그것이다 — "결론이 캡션에 말로만 있다".
005는 형식만 바꾼 것인데 손볼 게 없었다. **말할 것이 정해져 있으면 형식은 따라온다.**

**형식을 먼저 말하면 재작업이 나고, 결론을 먼저 말하면 안 난다.**

## 1. 결론 — 가장 중요하다

한 문장으로, 숫자 말고 **뜻**으로 쓴다.

  좋다  "정산이 본품 한 종에 쏠려 있고, 두 달치가 미입금이다"
  좋다  "신용잔고는 거래대금을 한 달 늦게 따라간다"
  나쁘다 "월별 추이를 보여줘"            ← 형식이다. 결론이 아니다
  나쁘다 "현황을 요약해줘"               ← 무엇을 알아야 하는지가 없다
  나쁘다 "매출 3,869,000원을 강조해줘"   ← 수치는 원천에서 온다. 결론은 뜻이다

**결론을 모르겠으면 그렇게 적어라.** "데이터를 보고 결론 후보를 먼저 제안해 달라"가
정당한 요청이다. 그때는 장표를 만들기 전에 후보를 올린다.

## 2. 원천

파일 경로. 시트·범위까지 알면 왕복이 준다.
**여기 없는 수는 장표에 못 들어간다** — 검사기가 막는다.
파생값(비율·합계·증감)은 원천 셀을 조합해 만들 수 있으니 그렇게 적으면 된다.

## 3. 독자

경영진이면 "왜"가 먼저 보이게, 실무면 "얼마"가 먼저 보이게 짠다.
같은 데이터로 004(표 중심)와 005(차트 중심)를 만들어 비교했다.

## 4. 형식

**모르면 "자유"라고 적는 편이 낫다.** 결론이 정해져 있으면 형식은 거기서 나온다.
지정하고 싶을 때만 적는다.

## 5. 제약

밝혀야 할 한계를 여기 적는다. 안 적으면 장표가 실제보다 좋아 보인다.
  "판매 데이터 기준일이 26일이라 이번 달은 마감 전"
  "광고비·물류비 미입력이라 최종 수익은 과대"

## 적지 않아도 되는 것

좌표, 폰트, 색, 글자 크기, 여백, 표 서식.
전부 `house-rules.yaml`이 정한다. 여기 적으면 규칙과 갈라진다.

## 짧은 판

급하면 1번과 2번만 적어도 된다. 나머지는 내가 정하고 무엇을 정했는지 보고한다.

## 결론을 모르겠을 때 — `make_brief.py`

원천 엑셀만 있으면 초안을 기계가 채운다.

```
python3 make_brief.py <원천.xlsx> -o brief.md
```

시트를 훑어 **쏠림 / 0인 항목 / 편차 / 상태 문자열**을 찾고 **셀 주소와 함께** 낸다.
요약 수치 블록(이름 → 셀 → 값)도 같이 뽑아 2번 칸을 채운다.
사람은 1번 결론 한 줄만 고르거나 고치면 된다.

**해석은 붙이지 않는다.** 나오는 문장은 전부 시트에서 읽은 사실이고 근거 셀이 붙는다.
잡히는 것이 없으면 "없다"고 말한다 — 억지로 만들지 않는다.

실측(2026-08-30, 올리브영 원천): 상위 여덟 개 안에 실제로 쓴 결론이 다 있었다 —
미입금 상태, 소비자매출 쏠림 60%, 판매수량 쏠림. 셀 주소까지 맞았다.
