# 디자인 시스템 스펙 (하우스 스타일)

ELS 과징금 감경 보고서에서 출발해 경쟁사 CIR 분석 최종 보고('26.7)로 확정된 사내 디자인 문법.
완성 모범 사례가 `assets/reference_example.pptx`(표지+Executive Summary+본문 장표)에 동봉되어
있다. 새 장표 제작 전 3페이지를 렌더해 눈으로 확인하면 문법을 가장 빠르게 익힐 수 있다.

## 판형·폰트

- **A4 가로**: `pres.defineLayout({name:"A4L", width:11.6929, height:8.2677})`
- 여백: 좌우 0.65in → 콘텐츠 폭 CW = 10.39in
- 폰트: **Arial** 단일 지정(한글은 시스템 폴백; 사용자 PowerPoint에서 맑은 고딕 계열로 표시됨)

## 팔레트

| 역할 | 색상 | 용도 |
|---|---|---|
| navy | 0D4D79 | 제목 구분선, 섹션 제목, 핵심 숫자, 배너/카드 배경, 표 헤더, 당사 막대 |
| amber | FFC000 | 배너 결론 줄, 강조 카드의 핵심 숫자, 리테일/보조 계열 막대. **한 페이지에 절제해서** |
| blue | 0057D9 | 증감·델타 수치 전용 (+4.1%p 등) |
| title | 1F2937 | 페이지 제목, 진한 본문 |
| body | 3C4350 | 일반 본문 |
| gray | 6B7280 | 각주, 보조 라벨 |
| grayLt | C4CAD2 | 패널 테두리, 경쟁사 막대, 표 괘선 |
| steel | C9DAE8 | 당사 열 하늘색 배경, 다크카드 보조 텍스트 |
| tint | E7EEF4 | 옅은 블루 박스(캡션·강조 배경), 당사 열 밴드 |
| tintLt | F1F5F9 | (사용 자제 — 표 줄무늬는 기본 금지) |
| divLt | DDE1E6 | 패널 내부 구분선, 옅은 그리드 |
| amberTint | FFF1CC | 열위 표시 필요 시(기본 미사용) |

빨강(FF0000)은 **결론·핵심 강조 전용**: 본문 장표의 "⇒ 결론" 구문과 공식 양식
(Executive Summary) 키워드에만 쓴다(줄당 1개 이내). 숫자 음수 표기는 **마이너스 부호(-)**(△ 금지, 빨강 금지),
열위 표시는 앰버틴트 또는 무표시.

**회사 공식 브랜드 스와치**(양식 레이아웃 내장, formal-report.md 상세):
0D4D79(딥블루) / 602800(다크 브라운) / FFC000(앰버) / FFDC6D(라이트 앰버) / FFF2CC(크림 틴트).
1page 하우스 팔레트의 navy·amber는 이 공식 팔레트와 동일 계열이다.

## 폰트 이원화 (HY헤드라인M / 맑은 고딕) — '26.8 확정

- **HY헤드라인M + bold**: 페이지 제목, 배너(요약박스), 공식 양식의 "Executive Summary" 제목
- **HY헤드라인M, bold 없음**: 섹션 칩 라벨. 칩은 배경이 네이비라 굵게 하면 뭉개진다
- **맑은 고딕**: 그 밖의 전부(표, 불릿, 카드, 캡션, 각주, 크림박스, Executive Summary 본문)
- Executive Summary 본문의 `[대괄호 섹션 제목]`만 HY헤드라인M(bold 없음), 나머지 줄은 맑은 고딕 bold
- HY헤드라인M은 맑은 고딕보다 15~20% 넓다. 배너는 **15pt**로 낮추고 한 줄 **36자 이내**로 끊는다.
  칩 폭은 글자수 × 0.20in + 0.35in 이상으로 잡는다(10자 → 2.35in)
- 렌더 검증 환경에는 두 폰트가 없어 대체 폰트로 표시된다. 줄바꿈은 실제 PowerPoint에서 한 번 더 확인한다

## 타이포 최소 크기 (엄수)

**본문 텍스트는 10pt 미만 금지.** 작은 글씨는 콘텐츠를 빈약해 보이게 한다.
예외: 각주 8pt, 표 셀 9pt, 차트 값 라벨 9pt, 표 하단 캡션 9pt, ▸ 마커 9pt.
크기 위계: 배너 16pt > 칩·콜아웃 12pt > 서브헤더 10.5pt > 본문 10pt.

## 공통 컴포넌트 (좌표는 A4L 기준 — '26.7 최종본 확정 문법)

- **헤더**: 제목 16pt bold 1F2937 @ (0.65, 0.55), 폭은 CW 전체.
  **우측 본부명·날짜 표기 없음. 제목 아래 구분선 없음**(바로 아래 배너가 구분 역할)
- **배너**: navy rect **(0.65, 1.06, CW×0.79)**. 텍스트 2줄 **16pt bold**
  (1줄 흰색 사실, 2줄 앰버 결론; 흰 줄 안에서도 핵심 구는 앰버 런 혼합 가능).
  괄호 보조 수치는 **11pt** 인라인 런으로 크기만 낮춘다. lineSpacing 1.18
- **섹션 칩**: 번호(①②③) 패널 대신 **네이비 라운드 사각 칩(1.77×0.28, radius 기본)**
  + 흰 12pt 텍스트. 칩 우측에 보조 설명 텍스트 10pt gray "(판관비 ÷ 순영업수익, %)".
  좌측 콘텐츠(표·차트)는 **테두리 박스 없이** 칩 아래 y+0.35부터 직접 배치.
  우측 보조 영역이 필요하면 흰 rect(테두리 없음)만 깔고 그 안에 콜아웃·불릿 구성
- **콜아웃 행**: 서브헤더 10.5pt navy bold → 핵심 수치 12pt navy bold + 비교값 10~11pt gray
- **▸ 불릿**: navy ▸ 9pt(별도 박스) + 본문 **10pt**(강조 navy bold).
  **결론 "⇒ ..."는 FF0000 bold 허용**(줄당 1개, 페이지 핵심에만).
  **⇒ 줄에는 ▸ 마커를 붙이지 않는다** — 화살표가 이미 마커 역할을 하므로 두 개가 겹친다
- **줄글만 있는 영역(불릿 블록)**: 뒤에 아주 옅은 회색 바탕(F7F8FA, 테두리 E8EBEF) 패널을 깔아
  표·차트 영역과 구획을 나눈다. 불릿은 패널 안쪽으로 0.16in 들여쓰고,
  **불릿 블록의 상하 여백이 같아지도록** 시작 y와 step을 잡는다
- **시사점(크림 박스)**: 페이지 결론은 하단에 **크림 박스(FFF2CC, 테두리 FFDC6D)** 로 넣고
  **검은색(000000) 일반 글씨 10pt**로 쓴다. 배너와 같은 네이비 박스를 하단에 또 깔면 시선이 분산된다.
  2줄이 되면 문장 경계에서 줄을 나눈다. 구버전의 "시사점: " 행과 다크 강조 카드는 이것으로 대체한다
- **다크 강조 카드**: 사용 자제(크림 박스로 대체). 부득이한 경우 navy rect, 제목 앰버 **12pt** bold + 본문 흰색 **11pt** bold
- **스탯 카드**: 흰 배경 grayLt 테두리, 숫자 15~22pt navy bold + 라벨 gray 10pt
- **KPI 흐름 스트립**: 카드(2.26×1.08) → 화살표(rightArrow) + 델타(blue 12pt) → 카드.
  강조 카드는 navy 반전(숫자 앰버)
- **표 하단 캡션**: 9pt, "* "로 시작(핵심 판독 한 문장, navy bold 가능)
- **각주**: 페이지 하단 8pt gray, ※/*/** 순. **하단 구분선 없음.** 총 4행 이내.
  **바닥 기준으로 붙인다**: 줄 수와 무관하게 마지막 줄이 같은 높이에 오도록
  `y = 7.70 - 0.14 × 줄수` (1줄 7.56 / 2줄 7.42 / 3줄 7.28).
  페이지마다 y를 다르게 주면 연속으로 넘겨볼 때 각주가 위아래로 흔들린다.
  공식 양식 마스터의 하단 가로선이 y≈7.83in에 있으므로 이 선을 넘지 않아야 한다
- **아이콘**: 지름 0.34in **원형 배지(navy 또는 tint) + 내부 글리프** 단일 규격으로 통일,
  같은 행의 아이콘은 y 좌표 정렬. 크기·모양 혼용 금지
- **도형(체브론 등) 안 한글**: 글자 단위 파단 금지("적립/금" 불가). 텍스트는 도형에 넣지
  말고 **도형보다 넓은 별도 오버레이 텍스트 박스**로 얹어 단어 단위 줄바꿈을 보장한다.
  텍스트가 도형 폭을 약간 넘는 것은 허용
- **시안 태그**: 우하단 (8.4, 8.0) 8pt grayLt 우측 정렬

## 차트 (전부 도형으로 그림)

- **100% 세로 스택**: slot ≈ 0.55~0.86, bar폭 0.4~0.52. 세그먼트 색: 앰버(리테일 등
  관심 변수) / navy(구조 강조) / grayLt(중립). 라벨은 세그먼트 안 중앙 8.5pt
  (앰버·회색 위엔 1F2937, navy 위엔 흰색)
- **그룹 세로 막대**: 계열 2개(당사 navy / 비교 grayLt 또는 앰버·navy), bar폭 0.2~0.3,
  값 라벨 막대 위 7.5~8.5pt. 축은 baseline 라인만(grayLt), 그리드 생략
- **워터폴(치환 시뮬레이션)**: 실제(navy) → 공중 델타(앰버) → 가상(grayLt),
  점선 연결 `addShape("line", {dashType:"dash"})`, 0/25/50% 눈금은 divLt 가는 선 + 7.5pt gray
- **레인지 바**: min~max 구간 rect(당사 앰버/경쟁사 grayLt), 단일값은 작은 마커.
  라벨이 축 우측 끝을 넘으면 막대 왼쪽에 우측 정렬로 배치
- **당사 강조**: 당사 막대(군) 뒤에 tint 배경 밴드를 먼저 그린다
- **평균선**: blue 1pt dash + 우측 위 라벨 7.5pt blue bold

## 표 규칙

- **정렬: 전 셀 중앙정렬이 기본.** 헤더는 예외 없이 중앙정렬한다.
  좌측정렬은 **셀 안에서 줄바꿈되는 긴 서술문 열**에만 쓰고, 그 열도 헤더는 중앙정렬로 둔다.
  짧은 구절(단어~10자)은 좌측정렬하지 않는다 — 열 경계가 어긋나 보인다
- **행 높이 예산**: pptxgenjs의 `rowH`는 최소값일 뿐이고 PowerPoint가 실제로는 더 키운다.
  9pt + margin 3 기준 **1줄 0.33in, 2줄 0.58in 이상**으로 지정한다.
  0.30 이하를 주면 PowerPoint에서 0.347로 늘어나 **표 아래 캡션·칩과 겹친다**(실제 사고 사례).
  표 아래 요소는 `표 top + Σ rowH + 0.10` 이후에 배치한다
- 헤더: navy 배경 + 흰 8.5~9.5pt bold. 본문 8.5~9.5pt
- **바탕은 흰색 통일**(줄무늬 금지). **당사 열만 steel(하늘색) 배경 + navy bold**
- 소계·합계 행은 배경 없이 **행 전체 볼드**
- 음수·산출불가: "-7.0", "적자*", "-" (본문색 또는 gray, △ 금지, 빨강 금지)
- 우측 비교 열("당사-경쟁사평균"): 헤더는 개행("당사-\n경쟁사평균")으로 열폭 영향 차단
- **colW 합계 == w 필수.** 산출 후 `sum(col.width) == table width` 프로그래밍 검증
