# 테마 4종 — 선택 기준과 팔레트

shin-ppt(v4)는 팔레트가 하나로 고정돼 있었다. shin-ppt1은 **골격은 그대로 두고 팔레트만
갈아끼운다.** 생성 스크립트를 한 줄도 고치지 않고 `useTheme()`만 바꿔도 같은 페이지가
다른 톤으로 나온다. 역할 키가 13개로 고정돼 있고 호출부는 색 값을 직접 쓰지 않기 때문이다.

## 색 선정 기준

증권사 보고 자료에 쓸 수 있는 색인지가 먼저다. 아래 세 가지는 쓰지 않는다.

- **보라·자주 계열** — 국내 금융권 보고서에서 쓰지 않는 색이다. IT·SaaS 브랜드 색으로 읽힌다
- **형광·고채도** — 네온 시안, 형광 노랑, 핫핑크. 스크린에서 눈이 피로하고 인쇄하면 뭉갠다
- **초록·빨강을 증감 신호로** — 증감은 마이너스 부호로만 표기한다. 초록·빨강은 계열색으로만 쓴다

쓰는 색은 **감청(navy) / 청회(steel) / 심청록(teal) / 회청(slate) / 황동(bronze) / 벽돌(brick)**
여섯 가지 계통이다. 전부 채도를 낮춰 인쇄 시 톤이 무너지지 않게 조정했다.

## 고르는 순서

먼저 **인쇄본인지 화면인지**를 정하고, 그 다음 **색이 허용되는지**를 본다.

| 상황 | 테마 |
|---|---|
| 상급자 개인 보고, 타 본부장 보고. 기본값 | `report` |
| 대외 제출, 심의·감사 자료. 색이 조금이라도 소속으로 읽히면 안 될 때 | `mono` |
| 인쇄해서 손에 들고 보는 회장·이사회 보고 | `paper` |
| 계열이 셋 이상인 수치 페이지, 다열 표가 주인공일 때 | `dense` |
| 회의실 스크린 투사 | `report` 또는 `mono` (흰 지면이 스크린에서도 문제없음) |

한 덱 안에서 테마를 섞지 않는다. 같은 자료 안에서 지면색이 바뀌면 인쇄물에서 낱장이
섞여 들어간 것처럼 보인다. 인쇄본과 화면본을 나눠야 하면 **같은 생성 스크립트를 테마만
바꿔 두 번 돌린다.**

**네 테마 모두 밝은 지면이다.** 어두운 지면 테마는 두지 않는다. A4로 뽑으면 배경이
통째로 찍혀 토너를 쓰고 글자가 뭉개는데, 보고 자료는 결국 인쇄되기 때문이다.
스크린 투사는 흰 지면으로도 문제가 없다.

## report — 기본

shin-ppt v4 팔레트를 그대로 유지했다. 차콜 요약박스 + 심청록 강조다.

```
page FFFFFF   card FFFFFF   ink 1A1D21   body 3F464E   mute 8A929B
rule D5D9DE   accent 1F5C63 accentLt 7FB3BA  wash F4F6F7
dark 2A3138   onDark FFFFFF sky DCE9ED    msgInk 000000
series 1F5C63 / 5E7C8A / 8FA9B0 / B4C6CA / 3F464E / 8A929B
```

accent는 한 페이지에 한 지점만 찍는다. 세로바·강조 숫자·도식 강조 테두리 중 하나다.
셋 다 accent로 칠하면 강조가 사라진다.

## mono — 무채색 전용

유채색이 하나도 없다. accent가 ink와 같은 값이므로 **색으로는 아무것도 강조되지 않는다.**

```
page FFFFFF   card FFFFFF   ink 000000   body 3A3A3A   mute 767676
rule E0E0E0   accent 000000 accentLt B4B4B4  wash F5F5F5
dark 111111   onDark FFFFFF sky EDEDED    msgInk 000000
series 000000 / 4D4D4D / 8F8F8F / C4C4C4 / 666666 / A8A8A8
```

강조 수단이 셋으로 줄어든다. ① bold ② 테두리 두께(0.75 → 1.25pt) ③ wash 배경.
도식의 `hi` 옵션은 이 셋을 동시에 걸어 주므로 mono에서도 강조가 살아 있다.

흑백 프린터로 뽑아도 위계가 그대로 유지되는 유일한 테마다. 심의·감사 자료에 쓴다.
막대 계열이 넷을 넘으면 회색 단계가 구분되지 않으므로 **다계열 막대는 최대 4계열까지다.**

## paper — 크림 지면

크림 지면 + 감청 강조. 인쇄물에서 눈이 덜 부시고 종이 질감이 산다.

```
page F6F5F2   card FFFFFF   ink 2A2924   body 5A5548   mute 8A8478
rule DED9CA   accent 1F3A63 accentLt 9FB2CC  wash EBE8E0
dark 2A2924   onDark F6F5F2 sky E7ECF2    msgInk 16233A
series 1F3A63 / 4B7BA8 / 8A9AA8 / 5A5548 / A8813C / C9C3B3
```

이 테마에서만 **표에 `cardBg: true`를 쓴다.** 크림 지면 위에 흰 표가 얹히면서 종이 위에
카드가 놓인 것처럼 읽힌다. page가 흰색인 테마에서는 켜도 아무 차이가 없다.

계열색에 크림 계통(5A5548·C9C3B3)이 섞여 있어 지면과 이어진다. 막대가 지면에서 떠 보이지 않는다.

## dense — 다계열 수치

계열이 셋 이상인 페이지 전용이다. 핵심은 팔레트가 아니라 규칙이다.
**계열색은 선언된 순서를 모든 페이지에서 그대로 유지한다.**

```
page FFFFFF   card FFFFFF   ink 14181D   body 3C4550   mute 7C8794
rule DFE3E8   accent 1F3A63 accentLt 9FB2CC  wash F4F6F8
dark 1A2330   onDark FFFFFF sky E6EDF3    msgInk 14181D
series 1F3A63 / 4B7BA8 / 2E7D6B / 8A9AA8 / A8813C / 8C3B3B
```

감청 → 청회 → 심청록 → 회청 → 황동 → 벽돌 순이다. 앞의 넷은 한색 계통이라 인접해 있어도
명도 차로 구분되고, 뒤의 둘은 난색이라 다섯 계열 이상 쓸 때 확실히 갈린다.

**계열 순서를 페이지마다 바꾸지 않는다.** 1페이지에서 A부문이 감청이었으면 5페이지에서도
감청이다. 순서를 지키면 범례를 읽지 않아도 되고, 어기면 범례가 매번 필요해진다.

`2E7D6B`(심청록)과 `8C3B3B`(벽돌)은 계열색으로만 쓰고 증감 신호로 쓰지 않는다.
증감은 마이너스 부호로 표기한다.

## 테마를 새로 추가할 때

역할 키 13개를 전부 채우고 `series` 6색을 넣는다. 키를 늘리지 않는다.
키가 14개가 되는 순간 기존 테마 4종이 전부 그 키를 갖지 않게 되고, 호출부가
테마마다 다르게 동작한다.

색을 고를 때는 위의 **색 선정 기준** 세 항목을 먼저 본다. 웹 브랜드 팔레트를 그대로
가져오면 보라·형광이 섞여 들어온다. 채도를 낮추고 인쇄 렌더로 확인한 뒤 넣는다.

지면색을 흰색이 아니게 하려면 `card`를 `page`와 다르게 둔다(`paper`가 그렇다).
`darkPage: true`는 어두운 지면 테마를 굳이 추가할 때만 쓰는 스위치이고, 현재 쓰는 테마는 없다.
